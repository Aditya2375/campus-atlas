# Campus Atlas

Live: https://aditya2375.github.io/campus-atlas/

An interactive schematic planner, not a geographic map. Geometry, paths, zones, highlighted areas and pins are illustrative placeholders. North/South Campus and Maple/Cedar House are fictional. Do not use for navigation or building access. Coordinates are percentages on an invented canvas, not GPS.

Switch places, inspect sample pins, toggle layers, zoom/pan and add your own browser-local annotation. No backend/network connections. The former remote sample-pin loader was removed so no external payload can quietly change this illustrative map. Fonts are self-hosted with licenses.

`npm install`, `npm run dev`, `npm run build -- --base=/campus-atlas/`.

## Notes and backup

Notes stay in this browser. Export JSON before clearing browser data or changing devices. Stored records and submissions validate place/category/text and10–90percent finite positions; invalid saved objects are ignored.500note limit,1MB saved-input limit. Storage failure retains notes in this tab with a visible export-now warning. Deleting your local note asks for confirmation. No local notes are uploaded, synced or shared.

Real navigation needs verified georeferenced basemaps and landmarks, permission to use the data and an accuracy review. Do not repurpose this schematic as verified geography. Support: adityakulkarnicoding@gmail.com
